# Contribution Guidelines

This list is created by the community and wouldn't be possible without you! We appreciate and recognize [all contributors](https://github.com/hector6872/awesome-esp32/graphs/contributors)

- **To add to the list:** Submit a pull request
- **To remove from the list:** Open an issue

To set this list apart from and complement all other awesome lists, please follow these guidelines:

- Search previous suggestions before submitting a new one, as yours may be a duplicate
- List items should be sorted *alphabetically* within each section
- Each item should be limited to one primary link
- The link text should be the exact name of the project or resource
- Descriptions should be clear, concise, and non-promotional
- Descriptions should follow the link on the same line, e.g., `[Project Name](link) - Description`
- Mentioning the specific ESP32 target variant (e.g., ESP32-S2, ESP32-S3, ESP32-C3, ESP32-C6) in the description is optional but preferred when applicable
- Make an individual pull request for each suggestion

Please contribute links to projects and resources you have created, used, or are familiar with. This will help ensure high-quality entries

## Quality standard

To stay on the list, projects and resources should adhere to these quality standards:

- Generally useful to the community
- Functional
- Actively maintained (even if that just means acknowledging open issues when they arise)
- Stable, or progressing toward stable
- Documented
- Tests are preferred (when possible)

## Reporting issues

Please open an issue if you find anything that me be improved or have suggestions for making the list a more valuable resource. We realize sometimes projects and resources fall into abandonment or have breaking builds for extended periods of time, so if you see that, please let us know. We also realize that sometimes projects and resources are just going through transitions or are more experimental in nature. These can still be cool, but we can indicate them as transitory or experimental -- again, just open an issue. Thanks everyone!
